# Dunobo

Dunobo — Explore our world of knowledge.

Open educational platform with a responsive homepage, subject discovery, and a Human Atlas starter with a children's learning experience.

This repository is a public prototype. The original Human Atlas app source has not yet been imported; sample content is clearly marked as a preview.

## Local development

This version is a static website. Run `python3 -m http.server 8000` in the project root and open `http://localhost:8000`.

## Deployment

Publish the repository root as a static site to Cloudflare Pages, or another static host. No build command required. Connect a custom domain after DNS is configured.

## Scope

- Home and brand identity
- Responsive desktop/mobile navigation
- Browser-side search over current live sections
- Human Atlas and a children-friendly introduction/quiz
- Future subject placeholders (Quantum Biology, Anthropology, History)

## Quality safeguards

No invented audience statistics; children's features do not collect personal data. Science claims need references before publication. Brand clearance and full Human Atlas migration remain pending.
